Download Exelidoc

One Chrome/Edge extension adds Exelidoc to Gmail and Google Docs. The extension is currently installed from a developer download; it is not yet listed in the Chrome Web Store.

Browser Extension

Gmail & Google Docs

Download the source ZIP, extract it, and load the browser-extension folder in Chrome or Edge. After installation, click the Exelidoc toolbar icon and create your free account in the popup. Your session is saved automatically.

Download source ZIP

Chrome: open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extracted browser-extension folder. In Edge, open edge://extensions, enable Developer mode, then choose Load unpacked.

Beta limitation: signup does not verify email ownership, and signing into an existing account on a fresh install is not available yet.

Getting started

Install the Chrome/Edge extension, create your account in its popup, and start using it in Gmail and Google Docs.

01

Install the extension

Download the source ZIP from the Download page and extract it. In Chrome, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the browser-extension folder. In Edge, open edge://extensions, enable Developer mode, then choose Load unpacked.

02

Create your account

Click the Exelidoc icon in the browser toolbar, enter your email, and choose Create free account. Exelidoc creates your account and saves the session in the extension automatically; there is no API key to copy or paste. Free accounts include 50 AI requests per 30-day period.

03

Open Gmail or Google Docs

Open Gmail and focus a compose box, or open a Google Doc. Use the Exelidoc panel, enter an instruction such as "make this more concise" or "write a follow-up email," and click Ask. Edits are applied only on request and can be undone.

04

Generate a draft from the popup

Click the Exelidoc toolbar icon, enter a prompt under Generate text, and choose Generate. Copy the result into any document or message.

Getting started

About five minutes, start to finish.

01

Subscribe

Go to the Download page, enter your email, and complete checkout. You'll land on a page showing your personal API key -- keep that page open or copy the key somewhere safe.

02

Install the browser extension

Download it from GitHub, then in Chrome go to chrome://extensions, turn on Developer Mode, and choose Load Unpacked. Click the Exelidoc icon in your toolbar and paste in your API key.

03

Install the Office add-in

Download it from GitHub and follow the included setup steps for your platform. Open the task pane in Word, Excel, PowerPoint, or Outlook, and paste in the same API key.

04

Start writing

In Excel, corrections apply automatically as you edit cells. In Word and PowerPoint, they check as your selection moves. In Gmail, they check when you click out of a compose box. In Outlook, keep the task pane open while you write.

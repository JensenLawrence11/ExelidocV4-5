Chrome Web Store

A direct Chrome install is next.

The extension is being prepared for the Chrome Web Store. Once the listing is approved, you will be able to install it directly in Chrome without downloading Git files or using Developer mode.

  1. Install from Chrome Web StoreOpen the Exelidoc listing and choose Add to Chrome.
  2. Open ExelidocChoose the Exelidoc icon beside Chrome's address bar.
  3. Create your free accountEnter your email in the extension popup. Your session is saved in Chrome.
  4. Use it in Gmail or Google DocsOpen a draft or document and ask Exelidoc to help with text.

Separate developer preview

Office add-in package.

A separate Office add-in manifest is available for sideloading into desktop Office. It is not published in Microsoft AppSource and has not been fully tested by the maintainer.

  1. Download and extractUnzip the Office preview package to find its manifest file and setup notes.
  2. Upload the manifest in OfficeIn a supported desktop Office app, open the add-ins menu and choose the option to upload a custom add-in manifest.
  3. Sign in through ExelidocUse the same account session as the browser extension. Office functionality may differ and is not guaranteed.

Chrome Web Store

A direct Chrome install is next.

Install Exelidoc directly from the Chrome Web Store. No ZIP download or Developer mode setup is needed.

  1. Install from Chrome Web StoreChoose Add to Chrome on the Exelidoc listing.
  2. Open ExelidocChoose the Exelidoc icon beside Chrome's address bar.
  3. Create your free accountEnter your email in the extension popup. Your session is saved in Chrome.
  4. Use it in Gmail or Google DocsOpen a draft or document and ask Exelidoc to help with text.

Separate developer preview

Office add-in package.

The Office add-in is currently a manual developer preview, not an AppSource release. For everyday users, the easiest Office install will be an AppSource listing; that requires the add-in's sign-in and request flow to be verified first.

  1. Download and extractFor preview testing, unzip the package and use the manifest for your Office app.
  2. Add the manifestIn desktop Word, Excel, or PowerPoint, use the Add-ins menu to upload a custom manifest. Outlook has a separate manifest and setup path.
  3. Sign in through ExelidocUse the same account session as the browser extension. Office functionality may differ and is not guaranteed.
